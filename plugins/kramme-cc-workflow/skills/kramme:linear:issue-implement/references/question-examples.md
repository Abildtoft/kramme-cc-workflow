# Clarifying Question Examples

Use these as patterns for direct chat question prompts when requirements or implementation choices are unclear.

Ask the user directly in chat:
Question label: Implementation Scope
Question: The issue mentions {feature}. Should this include {related functionality} or just the core feature?
Suggested options:
- Core feature only — Minimal implementation as described
- Include {related functionality} — Broader scope with additional features
Ask the user directly in chat:
Question label: Technical Approach
Question: I found two patterns in the codebase for similar features. Which approach should we follow?
Suggested options:
- Pattern A - {description} — Used in {files}
- Pattern B - {description} — Used in {files}
Ask the user directly in chat:
Question label: Testing Requirements
Question: What level of test coverage is expected?
Suggested options:
- Unit tests only — Test individual functions/methods
- Unit + integration tests — Also test component interactions
- Full coverage including E2E — Complete test suite
